# RSS 출처

2026-11-13 공식 RSS 안내 페이지에 공개된 주소를 기존 수집 설정에 추가했습니다. 유료 API, 로그인, 구독 결제 없이 요청하는 개인 RSS 구독용 경로입니다. 무료 접근은 상업적 재배포·기사 전문 수집·외부 LLM 요약 권한을 의미하지 않습니다. body_sources 권한 설정은 추가하지 않았습니다.

KBS WORLD 안내에서 확인한 한국어 피드는 연예가 소식이므로 현재 5개 분야에 임의로 넣지 않았습니다. 일반 KBS·MBC, 동아일보·한겨레 등은 이번 작업에서 공식 분야별 주소/응답 확인을 완료하지 못해 추가하지 않았습니다. 무료로 쓸 수 있는 모든 언론사를 망라했다는 뜻은 아닙니다.

## 적용

현재 열려 있는 구버전 자동수집 프로세스는 Ctrl+C로 종료한 뒤 자동수집_시작.command를 한 번 다시 실행해야 새 코드를 읽습니다. 이후에는 5분마다 수집하며 config.json의 피드 목록을 매 주기 다시 읽습니다. 서버의 RSS 수집기도 매 주기 같은 config.json을 읽습니다.

현재 명령 실행 환경은 외부 RSS DNS 조회가 제한되어 새 31개 피드의 실제 기사 저장을 검증하지 못했습니다. 공식 안내의 주소 확인과 설정 검증, 기존 테스트 통과를 실제 수집 성공과 구분합니다. 실행 후 HTML의 출처별 수집 상태 또는 서버의 /v1/news/status에서 성공 여부를 확인하세요. 실패 피드가 있어도 기존 기사는 삭제하지 않습니다.

브라우저 화면과 JSON은 선택 날짜·분야별 5개 선정 한도를 유지합니다. DB에 새 출처가 들어와도 기본 어제 날짜나 선정 한도 때문에 화면에 모두 나타나지는 않습니다. 오늘 기사 보기를 이용하세요.
