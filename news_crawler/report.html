분야별 뉴스를 모아 내 관심사에 맞춰 읽습니다.

개인용 RSS 시제품 · 유료 API 없음

조회수·공감 순위가 아닙니다. 관심 키워드 점수 순으로 고르고, 동점이면 최신 기사부터 표시합니다. RSS의 짧은 설명만 사용하며 본문을 따로 수집하거나 AI로 요약하지 않습니다.

수집 상태와 이용 안내

RSS에는 최근 기사 일부만 남을 수 있으므로 모든 전날 기사를 보장하지 않습니다. 빈 분야는 다른 날짜로 채우지 않습니다. 첫날은 전날 기사가 부족할 수 있습니다. 자동 수집 중에도 이 화면은 정적 파일이므로 새 결과를 보려면 새로고침하세요.

이 화면은 개인 컴퓨터에서 사용하는 시험용 뉴스 리더입니다. SBS RSS는 개인 비상업적 사용으로 제한됩니다. 외부 공개·상업 서비스·재배포 전에는 각 제공처의 이용 범위를 확인하세요.

SBS RSS 안내 · 전자신문 RSS 안내

네트워크로 기사를 가져오는 작업은 Python 수집기가 수행합니다. 이 화면의 ‘관심사 적용’은 저장된 기사만 재정렬합니다. 관심사는 이 브라우저에 저장되며 다른 파일·브라우저와 공유되지 않을 수 있습니다. 자동 생성 JSON의 기본 관심사는 config.json에서 변경하세요.
