# 1단계: 주장과 연결 근거의 보수적 사실 검토

기준 main: f77e9ec. PR #11의 수량–대상 검사는 그대로 유지한다.
원래 숫자/날짜/인물/Evidence ID 거절 규칙과 사람 검토·승인 절차는 변경하지 않았다.

## 문제와 변경

전체 근거에 부정어가 하나라도 있으면 다른 사건을 정상적으로 요약해도 polarity 경고가 붙었다.
반대로 같은 문장 안에서 부정 대상을 바꾸거나, 인수 주체와 대상을 뒤집거나, 다른 행위를 주장하면 단어 집합 검사로 놓쳤다.
새 factual_relations 모듈은 제한된 동사와 명시적인 조사·수동태를 파싱해 연결된 근거 안에서 행위를 맞춘다.

- 동일 행위·대상에 대한 긍정/부정 충돌: predicate_polarity_conflict_suspected
- 예정/검토/가능성에서 확정·현재 사실로 강화: certainty_overstatement_suspected
- 명시적인 행위자와 목적어 교환: actor_object_reversal_suspected
- 동일 행위자·대상이지만 연결 근거의 행위가 다름: linked_event_mismatch_suspected

새 경고는 resolve_draft의 review_flags와 검토 문서의 factual_diagnostics에 표시한다.
지원 구문을 명확히 맞춘 경우에만 문장 전체의 부정·확정성 검사를 대신한다. 범위 밖이면 기존 경고를 유지한다.
모든 경고는 사람 검토용이며 자동 거절/자동 승인·문장 수정은 없다. entailment_verified는 항상 false다.
검증 실패가 아닌 진단 보강이므로 기존 승인 validator 버전은 유지한다. 캐시 적중도 기존 resolve_draft에서 재검사된다.

## 자체 작성 회귀 행렬

정상 재서술 14개, 오류 18개(탐지 범위 밖 복잡한 오류 3개 포함), 총 32개다.
독립적인 실제 LLM 표본이나 블라인드 holdout이 아니다. 아래 수치는 이 행렬의 경고 탐지 범위이며 LLM 정확도가 아니다.

| 지표 | 기존 경고 | 개선 경고 |
|---|---:|---:|
| 오류 경고 탐지 | 4/18 (22.22%) | 15/18 (83.33%) |
| 정상 사례 경고 | 6/14 (42.86%) | 1/14 (7.14%) |
| 인식 범위 내 오류 경고 | 4/15 | 15/15 |
| 복잡한 의미 오류 미탐 | 3/3 | 3/3 |

남은 정상 경고는 이중 부정 구문에 대한 기존 보수적 경고다. 임의로 사실 오류로 거절하지 않는다.
유효한 Evidence ID를 다른 행위 근거에 연결한 실제 resolve_draft 테스트도 추가했다.
기존 PR #11의 6개 왜곡/9개 정상 수량 회귀도 그대로 통과한다. backend 전체 134개 테스트 통과.

재현 (backend에서):

```sh
.venv/bin/python -m drivebrief_summary.factual_cases
.venv/bin/python -m unittest discover -s tests -q
```

## 범위 밖과 주의

대명사 해소, 이름 별칭, 간접적인 인과관계, 복잡한 인용·이중 부정, 시점 변화와 상충 보도, 임의의 동사 동의어는 의미 검증하지 않는다.
명시적인 조사·지원 동사 범위를 벗어나거나 근거끼리 충돌하면 일치/진실이라고 선언하지 않는다.
정상 재서술의 무경고 또한 참이라는 증명이 아니다. 원문 전체와 연결 근거의 의미적 함의는 사람이 검토해야 한다.
크롤러·DB·중요도·뉴스 그룹화·가중치·API 키는 수정하지 않았다.
