기준: git pull --ff-only origin main으로 받은 f77e9ec.

1. feature/claim-grounding-review: PR #11을 유지해 부정/확정성/행위자–대상/연결 근거 진단 보강, 정상/왜곡 회귀 행렬과 전후 경고 탐지율·오탐률. 자동 승인/자동 거절은 변경하지 않는다.
